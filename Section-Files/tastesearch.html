TasteSearch

An iOS app for finding restaurants by dish or craving

Swift SwiftUI SwiftData Google Places API Supabase PostgreSQL Row Level Security NaturalLanguage Apple Foundation Models MapKit CoreLocation Swift Testing GitHub Actions SwiftLint
View on GitHub ⬈

Overview

Type something like “birria tacos”, pick a location, and TasteSearch returns nearby restaurants filtered by dietary needs, price, and whether they are open. Results can be grouped by cuisine or shown on a map. The goal is to search by what you want to eat, not just by restaurant name or category.

The app is built entirely in SwiftUI with no third-party Swift packages. Restaurant data comes from the Google Places API, accounts and sync run on Supabase, and the language features run on the device with Apple's frameworks, so review text is never sent to a third-party AI service.

Features

Dish-first search

Natural queries are cleaned up (“i'm looking for birria tacos near me” becomes “birria tacos”) and searched with Google Places, then ranked by relevance, rating, reviews, distance, or hidden gems.

Smart filters

Dietary needs (halal, kosher, vegetarian, vegan, gluten-free, dairy-free, nut-free, healthy), price range, cuisine, open now, and search radius.

Flexible views

See results as a list, grouped by cuisine, or on a map. Restaurant pages add reviews, phone, website, directions, and a summary of what reviewers say.

Accounts and favorites

Sign in with email or username. Favorites and private notes are stored with SwiftData and sync across devices through Supabase.

Friends

Add friends by username and browse each other's favorite restaurants.

Group Swipe and Date Night

Swipe through restaurants with friends in a shared session using a join code or invite link, and get a ranked list of group matches. Date Night plans an outing from a plain-language request.

Architecture

  • UI. SwiftUI for iOS 18.5+, with a custom design system (glassmorphic cards, animated gradients, dark and light themes).
  • State. Plain ObservableObject managers for auth, favorites, friends, and theme, injected at the app root.
  • Local storage. SwiftData for favorites and search history, Keychain for the session, and UserDefaults for preferences.
  • Backend. Supabase Auth and Postgres, called directly over REST with URLSession instead of the SDK. Row Level Security protects each user's data, and SQL functions handle group sessions.
  • On-device AI. The NaturalLanguage framework and a bundled dish database and food lexicon parse queries and categorize cuisines. Apple Foundation Models (iOS 26+) power review summaries and dish suggestions.
  • Maps and location. MapKit and CoreLocation for the map view, distance sorting, and directions.

Testing and delivery

About 60 unit tests written with Swift Testing cover search filters, the dish database, the food lexicon, cuisine mapping, group swiping, and Supabase decoding, and they need no network or API keys. GitHub Actions runs SwiftLint, Gitleaks secret scanning, repository hygiene checks, and a build on every push and pull request. Documentation for each subsystem lives in the repository's docs folder.
